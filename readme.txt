Website: Alaya's Portfolio
Purpose: digitalize my physical artwork to be easily shared and stored safely. 
Pages:
1. home.html: Starting page that outputs a welcome message and image of my latest work. Also includes navigation and footer
2. gallary.html: Considered the main page contnet wise. Outputs side bar to navigate categories, my artwork in different sections, and descriptions. Also includes navigation and footer.
3. about.html: Outputs a short biography about me, and my image. Includes navigation and footer.
4. contact.html: Outputs a link to my email address and a form for user to submit their email and a question. Includes image and short message implying my contact is for anyone with a suggestion or question. Again has navigation and footer, this footer gives credit to the image as it is not mine. 
5. comments.html: Outputs the comments sent via the contact page. This page isn't available on the web page, it is a way to store the users email address privately.
